# Falcon Chemicals

Responsive single-page catalogue website for Falcon Chemicals in Menoufia, Egypt.

The site lists 44 chemical products with live search, category/status filters, product packaging mockups, and a quote request form that prepares an email to the sales team.

## Features

- 44 chemical products across ammonium, calcium, acids, lead, potassium, sodium, zinc, and other categories.
- Live search by compound, application, or product type.
- Category and availability filters.
- Product cards with generated inline SVG packaging visuals.
- Quote buttons that pre-fill the contact form.
- Contact form that opens a prepared email request.
- Direct WhatsApp and phone/email contact actions.
- Mobile navigation menu and resettable catalogue filters.
- Responsive layout for mobile, tablet, and desktop.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- No build step required

## Quick Start

Open `index.html` directly in a browser, or serve the folder with any static web server.

```bash
npm install
npm run serve
```

The npm server is optional. The website works as a static HTML file.

## Deployment

Deploy the folder to any static host such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
